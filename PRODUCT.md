# Personal site

Oliver Newth's portfolio, n3wth.com, presents work, projects, art, writing, a component library and contact information. Visitors explore through ordinary primary navigation and site search; writing and public content remain available in static HTML.

## Platform

Web. Astro renders routes and React hydrates interactive islands. Shared site identity, controls, typography and theme belong to the existing workspace packages.

## Constraints

Preserve public routes, factual copy, installation credits, metadata and keyboard-accessible navigation. Respect reduced motion. Oliver approved replacing the homepage's WebGL landscape with the contour-landscape composition shown in this chat; navigation remains ordinary HTML above the artwork. No new product features are part of that change.
