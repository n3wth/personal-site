EGM is Google's open-source plugin for designing software with coding agents. The Elephant is the working session. It holds your project context and drafts the specification. Goldfish reviewers read the draft and the source it references, without the earlier conversation. You resolve the trade-offs and approve the design.

Use it when a feature needs design decisions before implementation. For a small, clear bug fix, use your normal workflow.

The canonical documentation lives in the [EGM repository](https://github.com/google/elephant-goldfish-model) and at [egm.dev](https://egm.dev). This page is a short path through it.

## Install

Install the complete plugin, then start a new session.

Claude Code:

```sh
claude plugin marketplace add google/elephant-goldfish-model
claude plugin install egm@egm
```

Codex:

```sh
codex plugin marketplace add google/elephant-goldfish-model
codex plugin add egm@egm
```

Antigravity:

```sh
agy plugin install https://github.com/google/elephant-goldfish-model
```

The [setup guide](https://github.com/google/elephant-goldfish-model/blob/main/docs/harnesses.md) covers other agents and known limits. Reviews require a session that can create fresh subagents. If your agent cannot create them, EGM stops the review.

## Try your first design

Open a project and choose a feature that needs design decisions. In Claude Code and Antigravity, commands take the `/egm:` prefix. In Codex, select the skill from the skill picker.

```text
/egm:egm-brainstorm Add webhook delivery to this project.
```

Discuss requirements and trade-offs. Fresh reviewers challenge the proposal, and the agent saves the agreed direction in `concepts_brief.md`.

```text
/egm:egm-draft
```

The agent turns the brief into `design_draft.md`, pausing after each section for your feedback.

```text
/egm:egm-review design_draft.md
```

Fresh reviewers check the design, its clarity, its fit with the code, and its implementation plan. Choose which findings to address. When you approve the design, ask your coding agent to implement it.

See [all seven skills](/docs/elephant-goldfish/workflows).

## What a review is

A Goldfish receives the document and its referenced source. It does not receive the conversation that produced them. A finding is a claim to check against evidence. A review does not replace tests or your own judgment.
